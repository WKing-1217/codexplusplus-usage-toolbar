# Codex++ Usage Toolbar

Codex++ 顶部用量栏：查看 ChatGPT 额度、API 钱包余额或当前密钥套餐，以及本机任务 Token、缓存和时钟。

**版本：1.0.0。** 独立用户脚本项目，依赖 Codex++ 的脚本加载功能，不是 Codex++ 客户端分发包，也不是 OpenAI 官方扩展。

## 能显示什么

- **ChatGPT 登录**：额度剩余比例、重置时间、接口提供的可用重置次数。
- **钱包计费**：当前查询密钥对应的钱包剩余余额。
- **套餐计费**：接口返回的套餐名称、剩余额度、日／周／月用量和有效期。不会凭供应商名称判断是否属于套餐。
- **密钥限额**：接口只提供密钥限额时显示密钥额度，不冒充钱包或套餐。
- **当前本机任务**：累计 Token、输入、缓存输入、输出、推理、缓存命中率和上下文剩余估计。
- **刷新**：本地时钟、手动刷新、账户与余额约 60 秒刷新、任务约 5 秒检查；隐藏窗口暂停轮询。

余额账户默认跟随 Codex++ 当前供应商。也可以单独选择已有 API 配置查看余额，**不会切换实际供应商或重启对话**。

## 兼容范围

| 项目 | 范围 |
| --- | --- |
| 系统 | Windows |
| Node.js | 24 或更新版本；24 已用于本地验证 |
| Codex++ | 1.2.56 用户脚本机制 |
| Codex 内置版本 | 26.831.20005、26.901.20858 |
| API 接口 | Sub2API `/v1/usage`、New API `/api/usage/token` |

客户端升级后，如未识别到受支持的版本，脚本会停止并报告兼容性问题；不会宽松匹配客户端内部代码。

## 安装

1. 安装上表所列版本的 Codex++ 和 Node.js。
2. 下载此仓库 ZIP 并解压，或克隆仓库。
3. 在解压目录打开 PowerShell：

```powershell
.\install.ps1
```

仓库已包含 `dist`，安装无需 npm 下载依赖。安装器会自动识别 Node 和当前用户目录，先校验发布文件，再安装用户脚本与单次余额查询程序。

安装后，在方便时保存工作并通过 Codex++ 正常重新加载客户端。安装器不会结束任何客户端进程。管理工具的“脚本市场 → 本地脚本”可查看 `codex-usage-toolbar.js`。

### 已有本地旧版

如果同名脚本由本项目早期本地安装器生成，可传入原安装收据；只有当前文件与收据的 SHA-256 一致才迁移：

```powershell
.\install.ps1 -PreviousReceipt '原安装目录\installation.json'
```

其他同名脚本会被保留，安装器会明确报错。

## 使用

点击顶部摘要展开详情。

- 使用 API 钱包时，摘要显示钱包余额。
- 使用套餐时，摘要显示套餐名称和剩余额度，详情列出周期用量与有效期。
- 查询对象切换时先清空旧数据；查询失败显示具体状态，不使用别的账户数据补位。
- 零余额、无限额度、到期、缺少字段分别处理。接口没有给出的数据保持未知。

New API 的令牌用量接口返回内部额度单位，本项目不按未经确认的固定倍率将它换算成美元。服务商扣费属于此密钥的账单统计，与当前任务 Token 分开显示。

## 回滚、卸载、状态

```powershell
.\rollback.ps1
.\uninstall.ps1
node .\scripts\manage.mjs status
```

回滚与卸载先校验现有脚本，保留备份，不碰账号、供应商配置或其他脚本。磁盘变化在脚本下次加载时生效。卸载后保留的查询程序不会自行运行。

运行数据、收据和备份存放于 `%APPDATA%\Codex++\usage-toolbar`；本机生成的脚本在 `%APPDATA%\Codex++\user_scripts`。这些文件不应提交到仓库。

## 凭据与通信

余额查询通过 Codex 的 `command/exec` 启动一个短时 Node 进程，采用只读文件权限和网络访问。它只读取所选 Codex++ 配置，使用该配置密钥访问其原有服务商的已知查询端点，返回经过筛选的额度数据后退出。

- 没有常驻服务、额外监听端口、计划任务或遥测上传。
- 密钥不写入用户脚本、命令参数、界面或日志；服务商错误正文不回传界面。
- 不携带密钥跟随 HTTP 重定向，不发送聊天正文。
- 不修改 WindowsApps、官方客户端归档、系统权限或启动快捷方式。
- 不执行购买、充值或消耗重置次数的操作。

## 开发与验证

```powershell
npm run build
npm test
npm run check
```

源码位于 `src`；构建生成不含本机路径的 `dist` 模板和校验清单；安装时才写入本机路径。安装器测试仅操作临时目录，不查询真实服务商。

验证情况与实际限制见 [VALIDATION.md](VALIDATION.md)。支持精确匹配的本机任务；远程任务不借用本机其他任务的数据，超过 16 MiB 的日志等待该任务下一次实时用量通知。
